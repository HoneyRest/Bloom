# Bloom — Buyer setup guide

## What this product is

**Bloom** is a **private web app** for cycle-synced Pilates planning—track phases, workouts, readiness, and progress in one page. No App Store required.

This is a **private web app. No login, no subscription.** Your entries save **locally in your browser** on the device you use.

---

## How to open the hosted app link

Open your seller’s static site URL (for example GitHub Pages):

`https://your-name.github.io/your-repo-name/`

Use **Safari** on iPhone or **Chrome / Safari / Firefox** on desktop.

---

## Add to Home Screen (iPhone / iPad)

1. Open the site in **Safari**.
2. **Share** → **Add to Home Screen** → **Add**.

---

## Use on desktop

Bookmark the URL or open **index.html** locally. Data is stored per browser profile.

---

## Privacy & local storage

**This is a private web app. No login, no subscription.** Your entries save **locally in your browser** on the device you use.

### Important warning

**If you clear browser data or switch devices, export a backup first.**

---

## Backup & restore (export / import)

### Export

Use the in-app **Export backup** flow. Files are typically named **`bloom-backup.json`**. Store copies outside the browser (cloud, email, USB).

### Import

Use **Import** with a JSON file **exported from Bloom**. Confirm prompts—restoring usually overwrites current data in that browser.

---

## Troubleshooting

| Issue | What to try |
|--------|----------------|
| Backup won’t import | Use a file exported from Bloom; check file isn’t corrupted. |
| Data gone after iOS update | Restore from **bloom-backup.json** if available. |
| Layout looks odd | Zoom reset; try landscape/portrait; update the browser. |
| GitHub Pages 404 | Ensure **index.html** is at repo root and Pages branch is correct. |
